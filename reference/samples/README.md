# Échantillons

Fichiers réels produits par Le Mans Ultimate sur le PC du pilote, utilisés par les tests et par les
captures d'écran.

- `results-P1-paulricard.xml`, `results-R1-paulricard.xml` — fichiers de résultats d'une séance d'essais et
  d'une course en ligne (`UserData\Log\Results`). **Les noms des pilotes ont été remplacés par des noms
  inventés** (balises `<Name>`, lignes du flux, auteurs du chat), les messages du chat par des lignes
  neutres, et les noms d'équipe qui reprenaient un nom de pilote ont été changés. Tout le reste (temps,
  positions, incidents, voitures) est d'origine.
- `telemetry-config.json`, `CustomPluginVariables.JSON` — fichiers de configuration du jeu, sans donnée
  personnelle.

Avant d'ajouter un nouvel échantillon : remplacer de la même façon tout nom de personne.
